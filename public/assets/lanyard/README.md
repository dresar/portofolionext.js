# Lanyard Assets

Untuk menggunakan Lanyard3D dengan full features, Anda perlu menambahkan file berikut:

1. **lanyard.png** - Texture untuk tali lanyard
   - Ukuran: 64x64px atau lebih besar
   - Format: PNG dengan transparansi (opsional)
   - Pattern: Garis-garis putih untuk efek lanyard

2. **card.glb** (Opsional) - 3D model untuk kartu
   - Jika tidak ada, komponen akan menggunakan geometry sederhana
   - Dapat diedit di: https://modelviewer.dev/editor/

## Catatan

- Jika file tidak ada, komponen akan menggunakan fallback (texture putih dengan pattern sederhana)
- Komponen sudah bisa bekerja tanpa file ini, tapi akan lebih baik dengan file asli
